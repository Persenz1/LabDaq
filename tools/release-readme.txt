LabDAQ · Windows x64 便携版

解压整个文件夹后运行 LabDAQ.exe，保留旁边的 _internal 文件夹。
已附带 Python、PySide6/Qt、NumPy/SciPy 和 Rust 采集核心，无需安装 Python。
DT9837C 需先安装原厂签名驱动与 Open Layers 运行库；本包不包含原厂安装程序。

请解压到当前用户可写的文件夹；默认记录保存在程序目录下的 recordings，可在界面中更改。
核心连接信息与界面缓存保存在程序目录下的 .runtime。
关闭界面会保留正在进行的采集或 AO 输出，重开可重新接回。
替换版本前，请先停止记录、采集和 AO，再关闭窗口。

AO 更新率：10、20、48、96 kS/s，默认 48 kS/s，与 AI 采样率独立。
周期波形频率必须低于更新率的一半；实际上限还受设备回读时钟限制。
峰值幅度为 0–3 V，偏置为 -3–3 V，|偏置| + 峰值幅度不得超过 3 V。
直流电平由偏置设置。输出运行时先停止并归零，再修改参数。
