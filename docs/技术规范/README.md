# 技术规范

这些文档说明现有代码的数据格式、通信方式和计算方法。LabDAQ 1.0 的桌面入口包括实时监视、信号输出和数据回看；分析、记录库及多组比较的相关代码仍保留在仓库中，当前界面没有提供入口。

| 文档 | 内容 |
| --- | --- |
| [数据流与存储](data-pipeline-and-storage.md) | 原始电压、传感器换算、记录格式、暂停分段、导出和分析算法 |
| [IPC 与硬件控制](ipc-protocol-spec.md) | 本地 TCP 协议、核心状态、命令，以及直接 USB 后端的协议资料 |
| [QuickDAQ 功能对照](quickdaq-feature-matrix.md) | 原厂软件参考能力、1.0 可用功能与仓库保留功能的区别 |

Windows 发布版使用原厂 Open Layers C 驱动。直接 USB/WinUSB 后端用于开发研究，其寄存器操作和 USB 数据封装不能直接当作原厂后端的实现说明。后续分析功能见[开发规划](../开发文档/未来功能开发规划.md)。
