# QuickDAQ 功能对照

原厂参考为本机查看过的 QuickDAQ 3.7.0.49，包含 FFT Analysis Option。表中区分 LabDAQ 1.0 的可用入口与仓库保留代码，不据此比较两款软件的性能或可靠性。

## LabDAQ 1.0 可用功能

| 方面 | QuickDAQ 参考能力 | LabDAQ 当前入口或实现 |
| --- | --- | --- |
| 输入 | DT9837 系列设备及通道参数 | 面向 DT9837C，4 路 24 位输入，可选物理通道子集 |
| 采样配置 | 采样率、量程、耦合和激励设置 | 195.313–105469 Hz 配置范围；逐通道 ±10 V/±1 V、AC/DC、DT9837C 的 2 mA IEPE |
| 传感器 | 名称、单位、灵敏度、测点和方向 | 支持上述配置及工程偏移、极性；单位 V 时不使用灵敏度 |
| 调零 | 通道零偏扣除 | 最近最多 1 秒电压均值作为软件零点，非记录时可撤销；原始文件不改写 |
| 记录 | HPF 文件、暂停和停止 | 原始电压 `raw.f64` 与 `metadata.json`；暂停时保留采集，恢复后记录分段 |
| 回看 | HPF 波形浏览 | 原生记录与受支持的 HPF Double 波形只读加载；支持时域游标 |
| 显示 | 时域图和测量读数 | 缩放、平移、冻结、通道显示选择；相对时间、电脑时钟和采样点横轴 |
| 游标 | 双游标与差值 | 吸附到实际采样点，显示 Δt、Δy、区间峰峰值及 `1/abs(Δt)` |
| 输出 | 原厂支持多类波形及发生器设置 | 当前界面和 Agent API 提供直流、正弦、方波和三角波；±3 V；更新率 10/20/48/96 kS/s |
| 导出 | CSV/TXT | 勾选通道的完整记录；原始电压、工程量或两者；CSV/TXT 带 JSON 元数据注记 |
| 自动化 | 原厂 Open Layers SDK | 本机 `LabDAQ-api.exe` 命令行及 `labdaq.api.LabDAQ` Python API，与 GUI 共用核心 |

LabDAQ 的采集核心与 GUI 分进程运行，关闭 GUI 不自动停止 AI、记录或 AO。这个设计允许重新接回会话，不保证硬件、驱动、磁盘或系统故障时仍能持续写盘。

Windows 发布版使用原厂 Open Layers C 驱动。其 AO 由 SDK 缓冲区供料，停止时尝试单值写入 0 V，并返回归零结果。直接 USB 后端的 32 KB FIFO、4×896 点封包及 Packet 53 属于开发实现，不能用来描述原厂发布后端。

## 仓库保留功能

以下相关代码存在于仓库，但当前 1.0 界面和 Agent API 没有提供对应入口：

| 功能 | 代码位置及范围 |
| --- | --- |
| 频谱、PSD、H1 及相干分析 | `labdaq/processing.py` 及隐藏分析页；见[算法说明](data-pipeline-and-storage.md) |
| 实时因果与离线双向滤波 | `StreamingFilter`、`filter_window`；不能据此宣称当前回看页有滤波控件 |
| 记录库和多组比较 | `recording_library.py`、`comparison.py` 等保留模块，当前没有产品入口 |
| 扫频、锯齿、噪声等 AO | Rust 底层存在更多波形，当前 GUI/API 限于上表四种 |
| 触发、多设备同步等控制 | 底层及开发代码保留；不作为当前用户手册承诺的操作流程 |

安装步骤见[用户指南](../用户手册/user-guide.md)，后续数据分析见[开发规划](../开发文档/未来功能开发规划.md)。
