# 原始数据、工程量与离线分析

本原型的数据链为：**设备/协议模拟器 → 原始电压 V → 原始记录**；另一条分支执行 **扣零点 → 灵敏度换算与极性 → 工程单位偏移 → 显示及分析**。显示滤波仅作用于派生数据。这样后续修正灵敏度、零点或滤波方法时，可以重新计算原始记录。

目前的模拟传感器灵敏度默认 **10 mV/N**，仅用于交互与数学测试。它不代表实验室传感器的真实参数。到工位后需要核对传感器和调理器输出：若传感器只提供 mV/V，而调理器含桥路激励与增益，必须先得到整条信号链最终的 **mV/N**，不能把 mV/V 直接填入本软件。

## 数据接口与零点

`labdaq.processing.ChannelSettings(index, name, unit='N', sensitivity_mv_per_unit=10.0, zero_volts=0.0, inverted=False, point_number=None, direction='', engineering_offset=0.0)` 描述每个已选物理通道。所有二维数组均按 **采样点 × 已选通道** 排列，列顺序与 `channels` 一致；物理通道编号可以不连续。测点号和方向是追溯元数据，不参与数值计算。

工程量换算为：

```text
工程量 = (原始电压 V − 零点电压 V) × 1000 / 灵敏度(mV/单位)
若勾选反向，再乘 −1
最后加工程单位偏移 engineering_offset
```

`unit='V'` 时不应用灵敏度，仍可扣零点、反向和工程单位偏移。换算始终复制输出，原始电压数组保持不变。工程偏移必须以有限数值给出，只是显示/导出单位下的加法偏移，不是 ADC 校准或测量误差补偿。其他单位字符串（N、kN、Pa、m/s² 等）仅用于表示用户已给定的单位，不自动执行单位换算。

调零的操作含义是：在无载荷且信号稳定时，取选定原始电压窗口的均值，保存为 `zero_volts`。调零不会校正灵敏度，也不是 ADC 的仪器校准。传感器标定、调理器增益、原厂 ADC 校准系数是不同问题。用户已用信号发生器和示波器评估当前测量精度，结论是满足当前实验需求，不调整校准或增加软件补偿。

一次记录开始时对通道设置取快照，因此录制期间界面锁定调零和灵敏度修改。若需要在实验中切换换算系数，后续应增加明确的分段参数记录；当前原型没有该功能。

## 会话文件

每次 `SessionRecorder(path, sample_rate, channels, source='simulation', acquisition_config=None)` 建立一个新会话目录。`sample_rate` 必须传入设备实际采用的采样率，而非未经取整的请求值。实时页通过 `recording_directory(root, experiment)` 和 `next_recording_path(root, experiment, condition, group)` 生成 `通用根目录/实验名/工况-序号`；空工况为 `未命名`，序号从 1 开始，正常收尾后由界面递增。已有路径不会被覆盖。记录库同时读取旧版根目录直属会话和新版一级实验子目录中的会话，不继续向更深层递归。

| 文件 | 内容 |
| --- | --- |
| `raw.f64` | 小端 IEEE 754 float64；单位 V；采样点优先交织；无文件头 |
| `metadata.json` | 格式版本、dtype、通道顺序、名称、单位、零点、灵敏度、极性、测点号、方向、工程偏移、实际采样率、数据来源、采集配置、实验名、试样/工况/备注、UTC 起止时间、实际样本数、文件关闭状态、停止原因及错误 |

4 通道、2 kS/s 时原始数据约为 **64 kB/s，230.4 MB/h**（十进制）。4 通道、最高 102.4 kS/s 时约为 **3.28 MB/s，11.80 GB/h**。不使用把整个实验保留在内存后再保存的方式；每块写入后刷新 Python 文件缓冲。该刷新不等于断电保护，也不承诺电脑突然断电时的文件系统持久性。

`source` 保存实际来源，例如 `simulation`。回放和 CSV 导出保留该值，不把模拟数据伪装成硬件数据。

`close(termination_reason='user_stop', error=None)` 保存停止原因和错误。`finalized=true` 只表示原始文件完成关闭并保存了样本数；设备断连后妥善关闭的记录仍为 `true`，但应同时看到 `termination_reason='acquisition_error'` 及对应错误。重复关闭不覆盖首次停止原因。CSV 自动保留这些元数据。

`load_session(path)` 只读取元数据和检查文件长度，不载入全部电压。返回对象提供：

```python
session.sample_rate
session.sample_count
session.duration
session.channels
session.metadata
session.path
session.read(start=1000, count=20000)  # 随机读取一段，单位为采样帧
session.iter_chunks(chunk_size=4096)  # 最后一块可以不足 4096 帧
```

`read(count=None)` 读取从起点到结尾的全部剩余数据，因此图形界面应始终传入有限 `count`。超出结尾的窗口返回实际可用的样本。应用意外退出但原始文件仍包含完整采样帧时，读取器可以从文件长度恢复可用样本数，保留 `finalized=false`。末尾不足一帧或已正常结束的会话长度发生变化时会明确报错。

`export_csv(session_path, output_path)` 逐块写出 CSV，第一行 `# labdaq_metadata: {...}` 保存完整 JSON 元数据；第二行为表头，依次包含所选时间列、原始 V 列和/或工程量列。源样本索引以本组采集起点为 0，包含记录前预览偏移和暂停缺口；源相对时间为该索引除以实际采样率，不将导出选区起点重新归零。只有从第 0 帧直接开始且无暂停的记录，最后一点才为 `(N-1)/fs`；`N/fs` 是实录帧数对应的时长，不包含暂停跨度。

例如 pandas 可用 `read_csv(path, comment='#', encoding='utf-8-sig')` 读取数值表。首行不是普通数据行，Excel 手动导入时应从第二行读取表头。CSV 并非原始采集格式，建议保留会话目录。

## 实验描述信息与多组比较

`recording_options` 保存 `duration_seconds`、`group_number`、`specimen`、`condition`、`notes`；实验名位于 `experiment`。当前实时页只编辑工况和序号，新记录的试样与备注为空；旧字段仍保留用于兼容历史记录和记录库编辑。这些文本随 JSON 预置和 Rust 核心配置恢复，记录开始后取快照。`update_recording_details(path, experiment=..., specimen=..., condition=..., notes=...)` 只允许修改可读且已收尾记录的描述信息，保留目录、组号、采样配置、原始帧和结束原因，并记录 `description_updated_at_utc`。元数据在相同目录写临时文件后原子替换，写回重新加载校验；短暂 Windows 占用只做有限次替换重试，持续失败仍报错。异常收尾组可以补充说明，但不会因此清除异常或允许批量导出。

`labdaq.comparison.ComparisonSource` 引用一个 `RecordedSession` 和该组自己的通道快照。只接受 `finalized=true` 的记录；采集异常收尾组也可只读比较，并保留异常提示。每组默认使用全部物理通道，也可由布局恢复明确的通道子集。`load_comparison()` 分块读取，逐组最多 200,000 帧，所有通道合计最多 2,000,000 个数值；达到上限时 `ComparisonResult.truncated=true`，界面明确提示，不把截断结果当作全记录。

比较横轴定义如下：

| 模式 | 显示横轴 | 对齐设置 |
| --- | --- | --- |
| `relative` | `源相对时间 - zero_seconds` | 默认第一个实录样本为 0；输入本组相对时间后取最近真实样本为零点，零点前可以是负时间 |
| `absolute` | `采集起点 epoch + 源相对时间 + shift_seconds` | 默认偏移 0；只使用采集起点或记录起点，缺可靠时间时拒绝，不用文件修改时间补造 |
| `samples` | `源样本索引 - sample_origin` | 默认第一个实录样本为 0；零点必须是实际存在的源样本索引 |

源样本索引与现有单组导出一致，是相对于本组采集起点的扫描位置，包含记录前预览偏移和暂停缺口。窗口起点包含、终点不包含；终点恰好落在真实样本上时不取该点。不同采样率按各自真实横轴叠线，不按行号拼接、不插值、不重采样。暂停位置只断开曲线，游标和导出仍只使用实际样本。工程值按单位分图，原始 V 可同图比较；各分图共享显示横轴，联动游标分别对所选曲线的真实样本取最近邻。手动零点和显示偏移不修改采集时间，也不代表硬件触发事件。

`export_comparison_csv()` 导出当前已加载窗口的长表，不为不同采样率建立公共宽表。每行包含 `recording`、`channel_index`、`channel_name`、`sample_index`、`source_time_s`、`comparison_x`，并按选择包含 `raw_V`、工程 `value` 和 `unit`。`comparison_x` 的含义由元数据中的 `axis` 决定；每组路径、采样率、对齐参数和原始元数据也保存在首行注记中。曲线显隐只影响看图，不改变当前窗口的数值导出。写文件先使用同目录临时文件，完成后替换目标；取消时不替换目标文件并清理临时文件，已有目标不会被当成新成功结果。

比较布局使用 `labdaq-comparison-v1` JSON，保存原记录路径、物理通道、三种对齐参数、横轴、窗口、显示数值、曲线显隐/颜色和分隔条尺寸。恢复时重新打开这些精确路径并校验记录、通道及真实样本零点，不静默替换缺失数据。旧布局缺少界面尺寸字段时仍可读取。

## 频谱的数值含义

`spectrum(data1d, fs, mode='amplitude', window='hann')` 返回频率与谱值。窗使用周期形式；数据不去均值，因此保留直流分量。

- `amplitude`：单边**峰值幅度谱**。以窗系数之和补偿相干增益，除直流和偶数点 FFT 的 Nyquist 频点外，正频率加倍。在远离直流/Nyquist 的整频点正弦输入下，峰值等于正弦幅度 A；RMS 为 A/√2。非整频点信号会产生谱泄漏，不能保证最大单个频点仍等于 A。
- `psd`：单边功率谱密度，单位为输入单位²/Hz。使用 `|FFT(xw)|² / (fs × sum(w²))` 并对有负频率对应项的频点加倍。对全谱执行 `sum(PSD) × Δf`，精确得到 `sum((xw)²) / sum(w²)`；矩形窗下等于原始信号的均方值。不要用对端点减半的梯形积分代替完整频点求和。
- Hann 窗下即使常数输入也会在相邻频点出现窗的频谱形状；直流频点的幅值仍正确。需要观察很小的振动分量时，应明确选择去均值分析数据，而不是将其默认为仪器调零。
- 含 NaN/无穷值的分析段直接报告无法分析，不默默补零或插值。

`frequency_response(reference, response, fs, nperseg=1024, window='hann')` 是明确限定的 **Welch H1** 分析：50% 重叠，每段减去均值，`H1=Pxy/Pxx`，其中 `Pxy=conj(X)Y`；同时返回幅值平方相干函数。假设噪声主要在响应侧。至少需要两个重叠段，避免把单段估计必然接近 1 的相干误当作测量证据。没有输入能量的频点返回 NaN；输入能量很低的频点即使存在数值结果，也不代表有可信的系统频响。

这只是可验证的初版算法，不等于已经覆盖 QuickDAQ 的全部频域选项：指数/线性/峰值保持平均、H2/H3 等后续需逐项按需求补充。当前官方手册未找到阶次/倍频程分析的功能依据，不将它们误列为原版必有功能；完整对照见 [QuickDAQ 功能基线](quickdaq-features.md)。

## 连续滤波

`StreamingFilter(sample_rate, channel_count, cutoff_hz, kind='lowpass', order=4)` 使用 Butterworth 二阶节（SOS）；`.process(block)` 继承上一块状态，`.reset()` 只在建立新流时使用。零初态产生正常的启动瞬态，因果滤波会带来相位和延时，不把它解释为传感器的真实相位变化。

这是显示/派生数据滤波，不能替代设备模拟/数字采样前抗混叠，也不修改原始记录。离线重算应使用相同参数并从目标记录起点连续处理，若只分析中间一段则需要额外的前置数据使滤波器稳定。

窗口频谱页面使用另一接口 `filter_window(data, fs, cutoff_hz, kind='lowpass', order=4)`：它对完整窗口执行 `sosfiltfilt` 前后向零相位滤波，不能用于实时因果控制。相比每次重建零初态的连续滤波器，它不会把每个静态载荷窗口重新当成阶跃。窗口边缘仍受端点延拓影响；短于所需延拓长度时明确报告数据不足。双向滤波的总幅频响应为单次滤波幅频响应的平方，所以界面所填 Butterworth 截止频率处总响应为 **−6 dB**，总阶数为单次的两倍；它不是同截止频率的单次 −3 dB 因果低通。

## 本轮验证与实机边界

针对性测试覆盖：mV→V 灵敏度换算、零点与极性、原始数组保留、已知正弦峰值/RMS、DC/Nyquist 不加倍、奇偶 FFT 长度、PSD 能量守恒、已知负增益 H1/相干、无能量频点、连续小块滤波与整段滤波等价、分块记录与末尾短块、随机窗口回放、换算参数快照、CSV 时间轴及元数据保留、未正常关闭会话的完整帧恢复。

这些测试验证软件数学和文件行为。它们不证明真实设备的 ADC 校准、采样时钟、丢包检测、USB 吞吐、传感器供电或 IEPE 设置正确。
