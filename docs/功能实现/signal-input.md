## 1. 传感器输入特性与换算规范

### 1.1 物理输入前端
- **通道范围**：AI0 ～ AI3（4 路同步单端 BNC 输入）；
- **电气特性**：支持 $\pm 10\text{ V}$（$\times 1$ 增益）与 $\pm 1\text{ V}$（$\times 10$ 增益）；
- **耦合与激励**：支持 DC 耦合与 AC 耦合（标称 $1.0\text{ Hz}$ 高通截止）；支持 $4\text{ mA}$ IEPE 恒流源激励。

### 1.2 传感器换算管线
系统输入换算公式为：
$$Y = \left(\frac{(V - V_{\text{zero}}) \times 1000.0}{S_{\text{sens}}}\right) \times (\text{Inverted} ? -1 : 1) + \text{Offset}_{\text{eng}}$$
- 传感器输出单位若为 $\text{mV/V}$（含桥路激励与调理放大器），需折算为系统最终进入 BNC 前端的总灵敏度（$\text{mV/EU}$）填入配置；
- 底层文件存储始终保存真实物理电压（单位：$\text{V}$），换算参数保存在会话元数据中。

## 2. 模拟测试信号生成规范

在离线开发与回归测试模式（`labdaq/signals.py`）中，系统支持生成标准的基准波形：
1. **正弦波 (Sine)**：用于测试幅值、频率与单边峰值谱相干增益；
2. **方波 (Square)** 与 **三角波 (Triangle)**：用于测试奇次谐波与滤波响应；
3. **阶跃信号 (Step)**：用于检验数字滤波器的启动暂态与阶跃响应；
4. **线性扫频 (Chirp/Sweep)**：用于测试频响传递函数 Welch H1 曲线；
5. **高斯白噪声 (Gaussian Noise)**：用于全频段激励与系统辨识验证。
