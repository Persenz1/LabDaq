# 信号输入说明

DT9837C 有 AI0–AI3 四路 BNC 输入，支持逐通道 ±10 V/±1 V、AC/DC 耦合和 2 mA IEPE。普通电压源或外部供电调理器接入时关闭 IEPE。

[数据流与存储](../技术规范/data-pipeline-and-storage.md)说明电压与工程量换算。单位 V 时允许灵敏度为 0；其它单位必须填写正的 mV/工程单位灵敏度。传感器标称 mV/V 时，先结合激励电压及调理增益换算。

开发用的 `labdaq/signals.py` 可生成直流、正弦、方波、三角、锯齿、阶跃、脉冲、线性扫频及高斯噪声。它是电压测试模型，不代表真实传感器或采集仪响应，不能代替实机测量。
