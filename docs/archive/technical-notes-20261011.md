## 1. 早期接口方案评估

在项目初期，对 DT9837C 在 Windows 平台上的接入路线进行了全方位对比评估：

| 方案路线 | 考查依据 | 早期评估定位 | 最终架构采纳结果 (1.0) |
| :--- | :--- | :--- | :--- |
| **Windows DataAcq SDK** | 官方安装包、C/C++ 手册 (`oldaapi32/64.dll`) | 官方标准 C-ABI 接口，成熟稳定 | **最终采纳**：作为生产级稳定数采核心的底层驱动支撑。 |
| **Windows DT-Open Layers .NET** | 官方安装包、完整类库手册 | 面向 .NET 托管环境，引入复杂 CLR 运行时 | 未采纳，优先使用纯 C 接口避免运行时膨胀。 |
| **Linux/macOS libuldaq** | 官方开源源码、MIT 许可 | 深入理解硬件通信协议与寄存器时序的关键参考 | 作为独立协议解析与模拟器开发的代码依据。 |
| **Windows 通用 WinUSB 通信** | Microsoft WinUSB 驱动、libusb | 用户态协议自维护，摆脱专用驱动依赖 | 保留为实验性开发与跨平台原型探索路径。 |

## 2. 独立通信层可行性初查

1. **设备识别与协议格式**：
   - 冷启动 PID `0x9839`，运行态 PID `0x3998`，厂商 VID `0x0867`；
   - A/B/C 共用 PID，驱动需通过 I2C 读取内部 EEPROM 偏移 `0x05..0x06` 确认 C 型号；
   - 通信基于 64 字节块命令包下发与 512 字节 ADC/AO 数据流管道。
2. **冷启动固件加载**：
   - 依赖 `DTFX2LDR_FW.c` 与 `DT9837A_FW.c` Intel HEX 镜像，通过 USB Vendor Control Request 写入 RAM。
3. **平台差异与电源管理**：
   - Linux 驱动记载 Windows 10 上电复位问题，原厂驱动通过配置 EEPROM `powerAlwaysOn` 解决。

## 3. 实物信号链与硬件参数

依据官方技术手册整理的 DT9837C 硬件技术规格：

| 项目 | DT9837C 硬件指标 | 工程说明 |
| :--- | :--- | :--- |
| **模拟输入通道** | 4 路，单端，同步采样 | 前端 BNC 接口，各通道独立 A/D 转换器 |
| **A/D 转换器** | 24 位 Delta-Sigma | 具有 39 个扫描周期的线性相位群延迟 |
| **输入电压量程** | $\pm 10\text{ V}$（增益 $\times 1$）及 $\pm 1\text{ V}$（增益 $\times 10$） | 每通道独立可配 |
| **采样率范围** | $195.313\text{ Hz} \sim 105,469\text{ Hz}$ | 受内部 PLL 锁相环分频步进控制 |
| **输入耦合** | AC / DC 可选 | AC 耦合高通截止频率 $-3\text{ dB}$ 为 $1\text{ Hz}$ |
| **IEPE 激励** | 4 mA 恒流源 | 专用于压电加速度计与动态力传感器 |
| **输入阻抗** | $1\text{ M}\Omega \,\|\, 20\text{ pF}$ | 高阻抗单端输入 |
| **模拟输出通道** | 1 路，24 位，$\pm 3\text{ V}$ | BNC 接口，独立更新率 $10\text{ kS/s} \sim 96\text{ kS/s}$ |
| **转速计与计数器** | 无 | DT9837C 硬件精简了 A/B 型号中的 Tach/Counter |
| **触发与同步** | 软件、外部数字 TTL、模拟阈值 | RJ45 接口用于设备间时钟与触发级联同步 |

## 5. 工位测试与准备事项记录

初次回工位接机测试时拟定的核验清单：

1. **硬件连接准备**：DT9837C 主机、原装 USB 屏蔽线、标准 BNC 屏蔽连接线；
2. **基线环境对照**：在 Windows 生产环境安装原厂驱动及 QuickDAQ，采集基线标准波形；
3. **信号源回接测试**：
   - 将 DT9837C 自带的 AO 端口物理连接至 AI0 输入端口；
   - 输出已知幅值和频率的正弦波及直流电平，验证 AI 采样链路的幅值响应与零点稳定性；
4. **采样率与连续性验证**：在典型采样率档位（$1\text{ kHz}$、$10\text{ kHz}$、$48\text{ kHz}$、$105.469\text{ kHz}$）进行连续采样压力测试；
5. **传感器与调理器接口确认**：明确现场测力传感器的灵敏度参数（mV/N）与供电模式，核准软件工程量折算系数。
