> [!NOTE] 归档定位与说明

> - 正式产品文档已全面重构为**四轨工程文档体系**（产品概览、用户手册、开发者指南、技术规范），面向实际用户与开发者的最新指南请查阅 [全局文档导航](../README.md)；

## 历史技术沉淀与正式规范映射

为便于后续维护人员追溯底层原理，本归档中的核心技术事实已提炼沉淀至正式工程文档中：

1. **固件加载与硬件校准**：FX2 两阶段固件加载流程与校准电位器地址已沉淀至 [开发环境指南](../开发文档/开发环境.md) 与底层驱动实现中；
2. **时钟分频与 ADC/AO 码值换算**：锁相环计算公式与 24 位偏移二进制换算已沉淀至 [底层协议与时钟规范](../功能实现/protocol-details.md)；
3. **HPF 数据解析与流盘规范**：HPF 只读回放与 `raw.f64` 存储格式已沉淀至 [数据流管线与存储规范](../功能实现/data-and-analysis.md)；
4. **QuickDAQ 能力基线**：功能对比表已精炼提炼至 [QuickDAQ 功能基线对照](../功能实现/quickdaq-features.md)。
