## 1. 硬件架构与系统标识

DT9837C 是专为噪声、振动与动态力测量设计的高精度 USB 数据采集仪器，内部主要由 Cypress EZ-USB FX2 微控制器（CY7C68013A）、Xilinx Spartan 系列 FPGA、4 颗独立 24 位 Delta-Sigma A/D 转换器以及 1 颗 24 位 D/A 转换器构成。

```text
       +------------------------------------------------------------------------+
       |                           DT9837C-BNC 硬件内部架构                     |
       |                                                                        |
[AI0] ──> [IEPE/耦合/量程] ──> [24-bit Δ-Σ ADC] ──┐                            |
[AI1] ──> [IEPE/耦合/量程] ──> [24-bit Δ-Σ ADC] ──┤                            |
[AI2] ──> [IEPE/耦合/量程] ──> [24-bit Δ-Σ ADC] ──┼─> [FPGA 编组与无损 FIFO] ──┐ |
[AI3] ──> [IEPE/耦合/量程] ──> [24-bit Δ-Σ ADC] ──┘                            │ |
                                                                               │ |
[AO ] <── [重建滤波/放大] <── [24-bit DAC] <──────── [32KB FIFO 输出缓冲] <────┼─┤
                                                                               │ |
                                [CY22150 锁相环时钟] ──────────────────────────┤ |
                                                                               │ |
                                [Cypress EZ-USB FX2 控制器] <──────────────────┘ |
       +------------------------------------------------------------------------+
                                             ▲
                                             │ USB 2.0 (High-Speed 480 Mbps)
                                             ▼
                                  [PC 操作系统与驱动层]
```

### 1.1 设备标识与两阶段固件枚举

DT9837C 采用基于 RAM 的固件下载机制，设备物理接入 USB 总线后经历两个枚举阶段：

| 属性 | 参数值 | 技术说明 |
| :--- | :--- | :--- |
| **USB 厂商 ID (VID)** | `0x0867` (Data Translation / MCC) | 官方厂商固定标识 |
| **冷启动产品 ID (Boot PID)** | `0x9839` (`VID_0867&PID_9839`) | 设备初次上电、FX2 片内 RAM 未加载固件时的初始 USB 标识 |
| **运行态产品 ID (Runtime PID)**| `0x3998` (`VID_0867&PID_3998`) | 固件加载并软复位后重新枚举的正式运行态 USB 标识 |
| **子型号验证 (EEPROM Subtype)**| 型号标识码 `4` (DT9837C) | 驱动通过 I2C 读取内部 EEPROM 偏移 `0x05..0x06`，确认型号为 C 型 |
| **设备序列号 (Serial Number)** | 32 位无符号整数 | 读取内部 EEPROM 偏移 `0x08..0x0B` 处的 4 字节小端整数 |

### 1.2 USB 通信管道与端点配置

设备定义了 5 个专用 USB 传输端点：
* **`0x01` (Bulk OUT)**：下发 64 字节控制命令字及寄存器配置。
* **`0x81` (Bulk IN)**：接收控制命令应答与寄存器回读包。
* **`0x82` (Bulk IN)**：ADC 采样数据高速连续传输管道（双极性交织流）。
* **`0x06` (Bulk OUT)**：AO 模拟输出连续波形生成供料管道。
* **`0x88` (Bulk IN)**：设备异步硬件事件及状态监测。

## 2. 模拟输入 (AI) 信号链与电气特性

### 2.1 物理通道与型号特性说明

* **模拟输入通道**：共 4 路独立单端输入通道（AI0 ～ AI3），前端采用标准金属屏蔽 BNC 接口。
* **测速计通道澄清**：DT9837C 硬件精简了同系列 A/B 型号中的转速计（Tachometer）与外部计数器（Counter）通道。系统模拟输入通道严格限定为通道 `0..3`。
* **通道子集选择**：硬件支持任意升序且不重复的通道子集采集（如 `[0, 2]`、`[1, 2, 3]` 等）。FPGA 在硬件级对选定通道进行采样打包，未启用的通道不消耗 USB 总线传输带宽。

### 2.2 量程、耦合与 IEPE 恒流源

每路模拟输入通道均具备独立的模拟调理开关阵列，由控制寄存器 2（Reg 0x02）位掩码进行数字化控制：

| 功能特性 | 参数指标 | 控制寄存器位定义 | 说明与工程使用规范 |
| :--- | :--- | :--- | :--- |
| **输入电压量程** | $\pm 10.0\text{ V}$（增益 $\times 1$）<br>$\pm 1.0\text{ V}$（增益 $\times 10$） | Reg 0x02 Bit 4～7<br>（`0`: $\pm 10\text{ V}$, `1`: $\pm 1\text{ V}$） | 小信号（如微振动或高灵敏度力传感器）可切换至 $\pm 1\text{ V}$ 量程，提升量化信噪比。手册标称的 $\pm 30\text{ V}$ 为过压耐受保护阈值，非正常测量量程。 |
| **输入耦合方式** | `DC`（直流）<br>`AC`（交流） | Reg 0x02 Bit 0～3<br>（`0`: DC, `1`: AC） | AC 耦合内置一阶高通滤波器，其 $-3\text{ dB}$ 截止频率为 $1.0\text{ Hz}$。准静态力与低频位移测量必须选用 DC 耦合。 |
| **IEPE 恒流激励** | $4\text{ mA}$ 恒流源<br>顺从电压 $\ge 18\text{ V}$ | Reg 0x02 Bit 8～11<br>（`0`: 关闭, `1`: 开启） | 专用于为内置压电集成放大器（ICP / IEPE）的振动加速度计或力传感器供电。普通电桥放大器或外供电变送器必须关闭 IEPE。 |

> [!WARNING] 硬件电气切换时序约束
> 当通道由 AC 耦合切换至 DC 耦合时，底层驱动必须严格执行安全时序：**先切断该通道的 $4\text{ mA}$ IEPE 恒流源，延时等待电容释放后，再关闭 AC 耦合电容**。此举可杜绝外部恒流电荷在直流切换瞬间对后端高阻放大器产生瞬态电平冲击。

### 2.3 24 位 ADC 量化编码与电压计算公式

* **ADC 转换器类型**：24 位 Delta-Sigma 同步转换器。
* **数据编码格式**：24 位无符号偏移二进制（Unsigned Offset Binary），打包存放于 32 位小端整数（`u32`, Little-Endian）的低 24 位，高 8 位固定为 `0x00`。
* **物理电压换算公式**：
  设当前通道量程为 $R$（$10.0\text{ V}$ 或 $1.0\text{ V}$），ADC 读出的 24 位原始码值为 $\text{code}$（$0 \le \text{code} < 2^{24}$）：
  $$V = \text{code} \times \left(\frac{2 \times R}{2^{24}}\right) - R$$
  * 码值 `0x000000` $\to -R\text{ V}$（负满量程）
  * 码值 `0x800000` ($2^{23} = 8,388,608$) $\to 0.0\text{ V}$（零点）
  * 码值 `0xFFFFFF` ($2^{24} - 1 = 16,777,215$) $\to +R - \frac{2R}{2^{24}}\text{ V}$（正满量程）

### 2.4 Delta-Sigma 数字滤波群延迟 (Group Delay)

Delta-Sigma A/D 转换器内部集成了线性相位有限长单位冲激响应（FIR）抽取滤波器：
* **固定群延迟**：滤波器固有带来 **39 个扫描周期（39 Scans）** 的群延迟（`GROUP_DELAY = 39`）。
* **驱动处理**：每次启动连续采集时，底层驱动与采集核心必须严格抛弃前 $39 \times \text{通道数} \times 4\text{ 字节}$ 的原始数据，确保呈现在波形图与流盘写入首个采样帧均为滤波器完全稳定后的真实物理测量值。

## 3. 采样时钟综合机制 (Clock Synthesis)

DT9837C 采用板载 $48\text{ MHz}$ 晶振作为基准源，通过 Cypress CY22150 可编程锁相环（PLL）与 FPGA 分频器综合生成采样时钟。

### 3.1 采样率范围与工作模式

* **连续采样率范围**：**$195.313\text{ Hz} \sim 105,469\text{ Hz}$**。
* **双时钟模式切换**：
  * **标准模式**（$\text{Rate} \le 52,734\text{ Hz}$）：ADC 内部抽取时钟分频基数 `ticks = 512`，控制寄存器 1（Reg 0x01）的 Bit 0 置 `0`。
  * **高速模式**（$\text{Rate} > 52,734\text{ Hz}$）：`ticks` 切换为 `256`，Reg 0x01 Bit 0 置 `1`，激活 ADC 翻倍过采样模式。
* **典型标称采样率档位**：$1\text{ kS/s}$、$2\text{ kS/s}$、$5\text{ kS/s}$、$10\text{ kS/s}$、$20\text{ kS/s}$、$44.1\text{ kS/s}$、$48\text{ kS/s}$（整数零误差）、$52.734\text{ kS/s}$、$96\text{ kS/s}$（整数零误差）、$105.469\text{ kS/s}$。

## 4. 模拟输出 (AO) 信号发生架构

### 4.1 硬件参数与 DAC 规格

* **通道数量**：1 路模拟输出，前面板标号 AO。
* **DAC 分辨率**：24 位。
* **硬件输出电压范围**：**$-3.0\text{ V} \sim +3.0\text{ V}$**（$\pm 3.0\text{ V}$ 双极性）。
* **更新率档位**：支持 $10\text{ kS/s}$、$20\text{ kS/s}$、$48\text{ kS/s}$、$96\text{ kS/s}$ 四档硬件更新率。
* **FIFO 硬件缓冲**：内置 32,768 字节（对应 8,192 个 24-bit 样本）硬件输出队列，通过独立 USB Bulk OUT 端点 `0x06` 流式供给。

### 4.2 DAC 量化与安全归零

* **量化编码公式**：
  $$\text{Code} = \text{clamp}\left(\text{round}\left((V + 3.0) \times \frac{2^{24}}{6.0}\right), 0, 2^{24} - 1\right)$$
  * $-3.0\text{ V} \to 0$
  * $0.0\text{ V} \to 0x800000$ ($8,388,608$)
  * $+3.0\text{ V} \to 0xFFFFFF$ ($16,777,215$)
* **幅值偏置安全红线**：
  $$\left|\text{偏置 } V_{\text{offset}}\right| + \text{幅值 } V_{\text{amplitude}} \le 3.0\text{ V}$$
* **停机硬件安全归零**：无论正常调用停止指令还是发生异常退出，底层核心向 DAC 发送控制指令写入码值 `0x800000`（$0.0\text{ V}$），杜绝端口残留直流偏压。

## 5. 原厂 Open Layers 驱动接入机制

LabDAQ 生产路径采用原厂 64 位 Open Layers C 动态链接库（`oldaapi64.dll` 与 `olmem64.dll`）。

### 5.1 驱动初始化与双缓冲队列

1. **子系统定位**：驱动初始化时调用 `olDaEnumSubSystems`，获取子系统类型 `OLSS_AD`（模拟输入）与 `OLSS_DA`（模拟输出）。
2. **环形缓冲管理**：采集引擎向 Open Layers 注册双环形缓冲队列。当硬件填满一个缓冲区时产生完成事件，核心工作线程在回调中提取数据并立即调用 `olDaPutBuffer` 将缓冲区重新入队，确保千兆级无缝连续流盘。
3. **正常停止时序**：停止连续流时，先终止数据提取线程，随后调用 `olDaAbort` 中止硬件时基，妥善释放缓冲区句柄，避免多线程内存竞态。
