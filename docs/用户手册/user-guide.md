# LabDAQ 1.0 用户使用指南

LabDAQ 面向单台 DT9837C，提供四路采集、原始记录、AO 输出、数据回看、测量游标和 CSV/TXT 导出。数据分析、记录库、批量导出和多组比较留待后续版本。

## 安装与启动

运行 LabDAQ Windows x64 安装包，按向导安装应用及原厂设备驱动、Open Layers 运行库。安装需要管理员授权；日常启动使用普通用户权限，不需要另外安装 Python、Conda 或 QuickDAQ，也不需要配置 WinUSB/Zadig。

从开始菜单启动 LabDAQ。程序自动发现并连接 DT9837C，连接成功后保持待机，不自动采集或输出。设备卡片显示“重新连接”或“断开设备”。断开只释放原厂驱动会话，不是硬件电源开关。

默认目录如下：

| 用途 | 目录 |
| --- | --- |
| 程序和内置运行环境 | `%ProgramFiles%\LabDAQ`，通常为 `C:\Program Files\LabDAQ` |
| 当前用户配置与运行状态 | `%LOCALAPPDATA%\LabDAQ` |
| 默认记录根目录 | Windows“文档”目录下的 `LabDAQ\recordings` |

程序安装目录可在安装向导中更改。配置和记录按当前 Windows 用户存放，不随安装目录改变。Windows“文档”位置若已迁移或重定向，程序使用其实际位置，通常为 `%USERPROFILE%\Documents`。

自动保存的核心配置是 `%LOCALAPPDATA%\LabDAQ\.runtime\core.profile.json`；同目录的 `core.json` 是连接端点，`theme` 是主题缓存。此目录是程序内部状态，不是原始记录目录，也不代表所有界面偏好均已持久化。

可在采集页选择其他记录根目录。当前选择在本次会话及接回已有后台时恢复；完全退出核心后重开 GUI 使用默认记录目录。卸载保留配置和已有记录。

## 实时采集与记录

1. 在“实时采集”右侧设置实验名、当前工况名称和序号。每组按“记录根目录/实验名/工况-序号”保存，工况留空时使用“未命名-序号”。正常收尾后序号自动递增；已有记录不会覆盖。
2. 选择每通道采样率，默认 5 kS/s，常用档位为 0.5、1、2、5、10、20、50、100 kS/s。请按信号带宽选择。开始后显示 Open Layers API 回读的实际采样率，时间轴和记录使用该值；它不是经外部时基校准的测量值。
3. 点击“编辑通道与传感器”，启用所需 AI 通道，设置名称、测点号、方向、单位、灵敏度、电压零点、工程单位偏移、量程、耦合及 IEPE。批量设置作用于全部启用通道，点击“应用设置”生效。
4. 确认设备已连接，点击“开始预览”，检查数值和波形。预览属于采集；待机不产生扫描或记录。
5. 如需载荷调零，在预览中点击“当前载荷归零”。使用最近最多一秒平均电压作为零点，只改变显示和派生换算，不改原始电压。“撤销调零”恢复最近一次零点；记录期间不能调零或撤销。
6. 选择记录时长：手动结束或指定秒数，然后点击“开始记录”。也可在待机时直接开始记录。定长组按实际采样率四舍五入到整数帧，到点保存并返回预览；后台核心在界面关闭后也会按目标帧数结束该组。
7. “暂停记录”期间预览继续，暂停样本不写入文件；“继续记录”保留源时间轴中的缺口。定长只累计实际记录帧数。
8. 点击“结束记录”只保存当前组并继续预览；“停止采集”结束 AI 采集并保存活动记录。AI 停止不改变 AO 输出。

通道换算顺序为：扣电压零点、按灵敏度换算、处理极性、加工程单位偏移。工程偏移和软件调零均不是仪器校准。普通调理电压通常使用 DC、关闭 IEPE；IEPE 按实际传感器要求设置。

默认名称为“通道1”至“通道4”，单位 V、量程 ±10 V、DC 耦合；测点号、灵敏度、零点及工程偏移为 0，方向留空，反向和 IEPE 关闭。测点号 0 表示未设置。V 模式不使用灵敏度；切换为其他工程单位后，需要填写大于 0 的灵敏度。

### 实时显示

- 每张通道卡可独立选择近一秒的最新值、首值、均值、最小值、最大值、RMS、标准差或峰峰值。标准差使用总体标准差；首值是近一秒缓冲中的第一个样本。
- “小数位”控制显示精度，不改变记录或导出数值。“显示/隐藏”控制曲线显隐，不改变通道采集和记录。
- “时间轴”可切换相对时间、绝对时间（电脑时钟）或样本号。绝对时间来自电脑记录的采集起点，不代表硬件同步时间。
- “窗口”设置显示秒数；每通道最多显示 200,000 点，高采样率下窗口上限相应缩小，不限制记录时长。手动缩放后暂停自动跟随，“适应窗口”恢复。
- “暂停滚动”只冻结图形，采集、读数及记录继续。“保存图像”保存当前波形为 PNG，不包含原始数据。

## 信号输出

进入“信号输出”，设置直流、正弦、50% 占空比方波或三角波。连接设备后即可使用 AO，不需要先启动 AI。页面切换不改变采集或输出状态。

左侧图形是设定波形预览，实际电压需要用 AI 或外部仪器回读。初始参数为 10 Hz 正弦、0.2 V 峰值、0 V 偏置、48 kS/s 更新率。直流电平由“偏置”设置。

- 输出范围为 ±3 V，偏置绝对值加峰值幅度不得超过 3 V；峰峰值为峰值幅度的两倍。
- 更新率为 10、20、48、96 kS/s，与 AI 独立；周期波形频率必须低于实际 AO 更新率的一半，界面会随档位限制输入。
- 点击“开始输出”后，核心确认运行，按钮显示红色“正在输出”，参数锁定。修改前先停止；连接中断时显示“状态未知”。
- “停止并归零”只停止 AO 并下发 0 V，不改变 AI 状态。结束、暂停或定长完成记录都不停止 AO。
- 如需 AO→AI0 回环，用 BNC 连接 AO 与 AI0，AI0 使用 DC、IEPE 关闭、±10 V、单位 V、零点 0，再开始 AI 预览。AI0 开启 IEPE 时不能启动 AO。

记录保存起始 AO 状态与期间启停事件；事件位置是软件观察的扫描位置，不代表 AI/AO 硬件同步或群延迟补偿。扫频、噪声、Burst 和硬件同步触发不属于本版输出界面功能。

## 数据回看与测量

进入“数据回看”，点击“打开记录文件夹”，选择含 `metadata.json` 和 `raw.f64` 的记录组；历史文件点击“打开 HPF”。HPF 只读打开，不改变原文件；不支持的结构会明确拒绝。

1. 波形下方“时间范围”条代表整段记录。拖动蓝色区域浏览其他时间段，拖动两端缩小或放大显示范围；它与图中缩放、平移同步。每次最多读取 200,000 帧。“适应窗口”恢复设置的显示时长并适应幅值。
2. “显示与导出通道”统一使用 AI0–AI3 标签，勾选控制显示和导出通道。
3. 横轴可切相对时间、绝对时间或样本号；暂停缺口断线显示，不补点。没有可靠起点时间的 HPF 不提供绝对时间，不用文件修改时间替代。
4. 打开记录后默认显示测量游标。拖动 A/B 竖线改变取样时间；拖动 A/B 字母时，上下改变字母位置、左右带动标线。也可在卡片输入相对秒数定位到最近真实样本。“游标回到窗口”把游标移回可见范围。
5. 卡片显示时间、幅值、Δt、Δy、区间峰峰值和间隔倒数。Δt、Δy 按 B−A 计算；`1/|Δt|` 是间隔倒数，不是自动测得的基频。

## 导出与文件格式

点击“导出数据”，选择 CSV（逗号）或 TXT（制表符），数值可选原始 V、工程值或两者。导出勾选通道的完整记录；显示窗口、时间范围条和游标不改变导出范围。

时间列可选秒 `time_s`、毫秒 `time_ms`、微秒 `time_us` 或源样本号 `sample_index`。导出保留原记录的扫描位置及暂停缺口，不重新归零。文件首行以 `# labdaq_metadata:` 保存 JSON 配置及导出说明。

导出在后台分块执行并显示进度。“取消导出”或关闭运行中的导出对话框会请求取消，在当前数据块结束后停止；若目标文件只写出一部分，界面会明确提示。

每组原生记录包含：

```text
recordings/
└── 实验名/
    └── 工况-序号/
        ├── raw.f64        # 原始电压，64 位小端浮点，样本优先排列
        └── metadata.json  # 采样率、通道换算、组信息、暂停分段及结束状态
```

原厂输入来源为 `vendor`。原始文件只存实录帧；元数据中的 `recording_segments` 保存暂停前后各段源扫描位置。采样或写盘异常保留真实结束原因，回看可读的完整帧。

在 pandas 中读取 CSV 时跳过元数据注释：

```python
import pandas as pd
df = pd.read_csv('export.csv', comment='#', encoding='utf-8-sig')
```

## 关闭、重连与异常

采集、记录和 AO 由后台 `labdaq-core.exe` 负责。关闭界面后，活动采集和输出继续；重新启动 LabDAQ 可接回原会话、配置和计数。核心通过本机动态端口通信，端点保存在用户数据目录，无需手动设置端口。

彻底退出时，先结束记录、停止 AI，并在输出页“停止并归零”，再关闭界面。没有活动采集和输出时，核心自动退出并释放设备。

拔掉 USB 后会显示连接错误，重新插入后点击“重新连接”，成功后手动重新开始预览或记录。“状态未知”表示界面暂时不能确认后台状态，不等同于采集已经停止。

GUI 关闭后的续录不能保证核心崩溃、系统故障或断电后的恢复。当前原厂路径的实际实验时长验证仍在发布前检查中；已知验证范围见源码中的发布前检查文档。
