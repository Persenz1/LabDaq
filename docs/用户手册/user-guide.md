# LabDAQ 桌面客户端用户操作指南

[项目首页](../../README.md) / [文档中心](../README.md) / 用户操作指南

---

LabDAQ 是面向 Data Translation DT9837C-BNC 动态信号采集仪设计的高性能工业级桌面数据采集与分析软件。系统采用“原厂 Open Layers C 驱动 + Rust 独立采集核心 + PySide6/Qt 表现层”的双进程解耦架构，提供 4 通道 24 位同步采集、实时示波监视、高可靠流式存盘、单通道 24 位模拟输出（AO）波形发生、历史数据回看、双测量游标分析以及多通道数据分块导出全流程功能。

---

## 1. 安装与启动

### 1.1 安装向导与运行环境

LabDAQ 发行版提供统一的 Windows x64 安装程序（`LabDAQ-<版本号>-windows-x64-setup.exe`）：
1. 双击运行安装程序，在弹出的用户账户控制（UAC）窗口中授予管理员权限。
2. 安装向导将自动解压并静默执行原厂 OEM 设备驱动与 Open Layers x64 运行库安装（`SetupOem.exe /s /v"/qn REBOOT=ReallySuppress"`）。
3. 安装程序内嵌完整的 Python 3.12 运行时、PySide6/Qt 图形库、NumPy/SciPy 数学库以及编译优化的 Rust 采集核心（`labdaq-core.exe`）。日常运行使用普通用户权限即可，无需配置 Python、Conda 环境，亦无需手动安装 WinUSB 或 Zadig 驱动。

> [!NOTE] 驱动安装与系统重启
> 若首次在全新的操作系统中部署原厂驱动，安装向导可能会在结束时提示需要重启计算机。请妥善保存当前未完成的工作并重启系统，使内核驱动模块与设备注册完全生效。

### 1.2 默认路径与目录结构

系统遵循标准 Windows 应用规范，运行路径与用户数据相互隔离：

| 目录用途 | 默认路径规范 | 说明 |
| :--- | :--- | :--- |
| **程序与运行环境** | `%ProgramFiles%\LabDAQ`（通常为 `C:\Program Files\LabDAQ`） | 存放主程序 `LabDAQ.exe`、命令行工具 `LabDAQ-api.exe`、核心程序及内置运行库 |
| **运行时状态与配置** | `%LOCALAPPDATA%\LabDAQ` | 存放端点凭据 `.runtime\core.json`、自动配置 `.runtime\core.profile.json` 及界面主题缓存 |
| **默认实验记录根目录** | `%USERPROFILE%\Documents\LabDAQ\recordings` | 动态跟随 Windows“文档”目录的实际系统重定向位置，存放原生测量数据 |

* **自选记录路径**：用户可在“实时采集”界面灵活更改数据记录根目录。自选路径将在当前工作会话及重新接回后台核心时持续保持；完全退出核心并重启后，系统默认回退至标准“文档”目录。
* **卸载与升级**：升级或卸载软件时，系统将完整保留 `%LOCALAPPDATA%\LabDAQ` 中的用户配置以及 `recordings` 目录中的全部历史实验数据。

## 2. 硬件连接与设备管理

### 2.1 物理接线指南

DT9837C-BNC 前面板提供 5 个标准 BNC 接口：
* **AI0 ～ AI3**：4 路单端模拟输入通道，内置独立 24 位 Delta-Sigma A/D 转换器，支持同步采样。
* **AO**：1 路模拟输出通道，内置 24 位 D/A 转换器，输出电压范围为 $\pm 3.0\text{ V}$。
* **TRIG / CLK (RJ45)**：专用多机时钟同步与外触发接头（非以太网网络接口）。

### 2.2 设备发现与连接

1. 使用原装屏蔽 USB 数据线将 DT9837C 连接至计算机 USB 2.0 或更高规格接口，指示灯应呈绿色常亮。
2. 从开始菜单启动 **LabDAQ**。桌面客户端将自动检索系统底层注册的原厂驱动会话并建立连接。
3. 连接成功后，顶部状态栏设备卡片显示设备型号（DT9837C）、出厂序列号与驱动版本，设备处于待机就绪状态。此时硬件不启动数据采集或信号输出。

> [!NOTE] 驱动会话与物理电源管理
> 点击设备卡片上的“断开设备”按钮，系统将安全释放当前操作系统进程对原厂 Open Layers 驱动会话的独占占用，便于其他诊断工具（如 QuickDAQ）访问仪器；此时硬件设备仍保持 USB 物理连接与供电待机状态。若需彻底切断硬件电源，请直接拔除 USB 连接线。

### 2.3 异常热插拔与重连恢复

若在运行期间 USB 数据线意外脱落或松动，界面状态栏将立即亮起黄色警示并显示“通信连接中断”。
* 重新稳固插入 USB 数据线后，点击设备卡片上的“重新连接”按钮。
* 驱动握手成功后，硬件恢复就绪状态，用户可直接点击按钮恢复预览或流盘。

## 3. 实时采集与传感器配置

### 3.1 采样率选择与时钟机制

在“实时采集”主界面的“采样率”下拉菜单中选择期望的采样频率。
* **硬件采样率范围**：$195.313\text{ Hz} \sim 105,469\text{ Hz}$。
* **常用预设档位**：`0.5 kS/s`、`1 kS/s`、`2 kS/s`、`5 kS/s`（默认）、`10 kS/s`、`20 kS/s`、`50 kS/s`、`100 kS/s`。
* **时钟回读机制**：启动采集后，硬件内部的 CY22150 锁相环（PLL）将综合生成名义采样时钟。界面状态栏与会话元数据中将实时显示驱动回读的真实实际采样率（例如 $105,468.75\text{ Hz}$），系统时间轴与时间戳换算均以该回读时基为准。

### 3.2 通道参数与传感器配置

点击界面控制区的“编辑通道与传感器”按钮，弹出通道详细配置窗口。系统支持独立配置各通道，亦支持多通道批量应用：

| 参数项 | 可选值 / 格式 | 说明 |
| :--- | :--- | :--- |
| **通道使能** | 勾选复选框 | 支持任意升序通道子集（如 `[0, 2]` 或 `[0, 1, 2, 3]`），未启用通道不占用 USB 带宽 |
| **通道名称** | 文本（默认“通道1”～“通道4”） | 实验标识名称，同步写入导出数据表头 |
| **测点编号** | 整数（`0` 表示未指定） | 试验传感器测点位置代号 |
| **安装方向** | 字符串（如 `+Z`、`-X`、`+Y`） | 空间坐标轴向，辅助模态分析与三向测力 |
| **物理单位** | `V`、`N`、`kN`、`g`、`m/s²`、`Pa`、`kPa`、`mm` 等 | 传感器量纲。若选择 `V`，则作为原始电压直通显示 |
| **传感器灵敏度** | 浮点数（$\text{mV / 单位}$） | 传感器标称灵敏度。单位为 `V` 时灵敏度设为 0；工程单位时需填入大于 0 的数值 |
| **电压量程** | $\pm 10\text{ V}$（增益 $\times 1$） / $\pm 1\text{ V}$（增益 $\times 10$） | 硬件输入量程。小信号测量切换至 $\pm 1\text{ V}$ 可提升量化分辨率 |
| **输入耦合** | `DC`（直流） / `AC`（交流） | 准静态力与低频信号选用 DC；AC 耦合高通截止频率为 $-3\text{ dB}$ @ $1\text{ Hz}$ |
| **IEPE 恒流源** | 开启 / 关闭 | 提供内置 $4\text{ mA}$ 恒流激励，专用于压电式加速度计或 IEPE 测力传感器 |
| **极性反转** | 开启 / 关闭 | 反转波形正负方向（乘以 $-1$） |
| **工程单位偏移** | 浮点数（当前工程单位） | 在换算后叠加的显示修正值，不改变底层原始电压 |

> [!WARNING] 电气耦合与 IEPE 恒流源切换保护
> 1. 采用普通电桥调理放大器、位移传感器或标准直流电压源时，必须选用 **DC 耦合** 并 **关闭 IEPE 恒流源**。
> 2. 仅在接入压电式振动传感器或 IEPE 动态力传感器时启用 $4\text{ mA}$ 激励，且输入耦合应配合选择 **AC 耦合**。
> 3. 驱动底层具备硬件保护时序：在由 AC 切换为 DC 耦合时，核心会自动先关闭 $4\text{ mA}$ 恒流源，防止充放电瞬态冲击前端电路。

> [!TIP] 传感器灵敏度换算提示
> 若传感器校准证书给出的灵敏度为 $\text{mV/V}$（如未配内置放大器的应变式桥路传感器），请结合外接前置电桥供桥电压（$V_{\text{ex}}$）与外部放大器增益（$G$），计算并填写最终输入到 BNC 端子的系统综合物理灵敏度：
> $$S_{\text{sys}}\ (\text{mV/N}) = S_{\text{sensor}}\ (\text{mV/V/N}) \times V_{\text{ex}}\ (\text{V}) \times G$$

### 3.3 数据换算链路

实时波形显示与工程量导出的完整计算链路如下：
$$\text{工程值} = \left(\frac{(V_{\text{raw}} - V_{\text{zero}}) \times 1000.0}{\text{灵敏度 } S\ (\text{mV/单位})}\right) \times (-1 \text{ if 极性反转 else } 1) + \text{工程偏移}$$
若单位设置为 `V`，则跳过灵敏度缩放，直接计算 $(V_{\text{raw}} - V_{\text{zero}}) \times (-1 \text{ if 极性反转 else } 1) + \text{工程偏移}$。底层流盘文件 `raw.f64` 始终保存原始未修正物理电压 $V_{\text{raw}}$。

## 4. 实时示波器与显示控制 (Live Scope)

### 4.1 高性能波形呈现

实时示波器基于 PyQtGraph 打造，采用多线程双缓冲流水线，在 100 kS/s 满速下依然流畅平稳。
* **窗口显示时长**：在顶部控制栏可设置波形显示的时间窗宽度（$1 \sim 60\text{ 秒}$）。
* **缓冲区上限**：受限于显卡与核心环形缓冲性能，单通道最大实时重绘点数为 200,000 点。当采样率超过 50 kS/s 且窗口拉长时，显示引擎会自动锁定最大点数并平滑滚动，该机制完全不影响流盘记录时长。
* **交互缩放与自适应**：
  * 在图表区域使用鼠标滚轮可缩放时间轴或幅值轴；按住鼠标左键可平移观察历史波形。
  * 用户执行手动缩放或平移后，波形自动跟随滚动将暂时挂起；点击右键菜单或控制栏的“适应窗口”按钮即可一键恢复全屏自适应与实时自动跟随。

### 4.2 实时统计指标卡片

波形图下方为各通道实时数据看板，展示当前通道最近 1.0 秒时间窗内的动态统计特征：
* **统计量模式选择**：每张卡片均可独立切换下拉菜单：
  * **最新值**（Latest）：最近接收到的单个采样点数值。
  * **均值**（Mean）：最近 1 秒数据段的算术平均值。
  * **最小值 / 最大值**（Min / Max）：数据段极值。
  * **均方根**（RMS）：有效值，表征信号总有效能量。
  * **峰峰值**（Pk-Pk）：$\text{Max} - \text{Min}$。
  * **标准差**（Std Dev）：总体标准差，反映脉动离散程度。
  * **首值**（First）：1 秒窗口起始点的采样读数。
* **小数位设置**：可设置 $0 \sim 6$ 位显示小数精度，仅调整界面文字格式，不改变原始流盘与数据导出的高精度浮点数值。
* **显示 / 隐藏曲线**：点击卡片上的勾选框可控制该通道在图表中的显隐，不影响底层采集与写盘。

### 4.3 辅助观察工具

* **时间轴模式**：
  * **相对时间**（Relative Time）：以启动采集的瞬间为 0.000 秒。
  * **绝对时间**（Absolute Time）：换算为计算机系统的实际本地时钟（格式为 `HH:MM:SS.sss`）。
  * **样本点数**（Sample Index）：以物理采样帧序号为横轴坐标。
* **暂停滚动**：点击“暂停滚动”可冻结当前示波器画面供静态观测；后台数据采集、流盘写盘以及统计卡片更新均不受影响。再次点击恢复滚动。
* **保存图像**：点击“保存图像”将当前图表导出为高清 PNG 格式截图，方便撰写实验汇报。

## 5. 软件调零与撤销机制 (Zeroing)

在传感器安装就位或试验机构受力预紧后，通常存在固定静态零偏。LabDAQ 提供了非侵入式软件调零工作流：

### 5.1 操作步骤

1. 确认硬件连接正常，点击“开始预览”，使波形与读数稳定刷新。
2. 机构处于无载基准状态时，点击界面上的“当前载荷归零”按钮。
3. 系统自动提取各活动通道**最近 1.0 秒内的全部有效原始电压的算术平均值**，作为当前通道的零偏基准（`zero_volts`）。
4. 示波器波形与读数卡片立即减去该基准值，显示读数归零。
5. 若误触或需返回原始状态，点击“撤销调零”按钮，系统立即从内存恢复上一次保存的基准偏置。

> [!NOTE] 调零规范与原始数据完整性
> 软件调零仅在软件算法层计算并扣除偏移量，**不会修改硬件出厂校准寄存器，也绝不篡改底层流盘文件 `raw.f64`**。`zero_volts` 参数完整记录在会话元数据 `metadata.json` 中，确保试验全过程具有无损可溯源性。
> 为防止破坏流盘时间连续性，在正在进行数据记录时禁止执行调零或撤销操作。

## 6. 模拟信号输出 (AO)

LabDAQ 具备独立的单通道 24 位 DAC 模拟信号发生引擎，通过前面板 AO BNC 端子对外输出激励信号。

### 6.1 输出控制面板

在主界面展开折叠抽屉“信号输出 · AO”，配置波形生成参数：
* **波形类型**：
  * **正弦波**（Sine）
  * **直流电平**（DC）：输出恒定直流电压，幅值锁定为 0，电平完全由偏置设置
  * **方波**（Square）：50% 占空比标准方波
  * **三角波**（Triangle）：线性对称三角波
* **更新率（DAC Update Rate）**：支持 `10 kS/s`、`20 kS/s`、`48 kS/s`（默认推荐）、`96 kS/s` 四档硬件更新率。
* **输出幅值与偏置安全边界**：
  $$\left|\text{偏置 } V_{\text{offset}}\right| + \text{峰值幅值 } V_{\text{amplitude}} \le 3.0\text{ V}$$
  * 软件界面实时校验电压极值。若偏置与幅值之和超出 $3.0\text{ V}$ 安全红线，启动按钮将自动锁定，输入框亮起黄色提示，杜绝 DAC 饱和削顶或过冲损坏外部设备。
* **频率限制**：周期波形频率必须严格小于更新率的一半（奈奎斯特频率限制，例如 48 kS/s 更新率下最高输出频率为 $< 24,000\text{ Hz}$）。

### 6.2 启停与安全归零

* **开始输出**：核对参数无误后点击“开始输出”，按钮切换为红色“正在输出”状态，参数栏自动锁定以防误动。
* **停止并归零**：点击“停止并归零”，底层核心立即向 DAC 发送归零控制原语（Packet 53），将硬件电平强制拉回 $0.0\text{ V}$（对应码值 `0x800000`），避免输出端残留静态直流电平。
* **独立运行特性**：模拟输出与模拟输入（AI）时钟互不干扰，无需启动 AI 采集即可独立开启 AO。

### 6.3 AO $\to$ AI0 物理回环自检

用户可自行执行回环测试以快速验证整机信号链路：
1. 取一根标准 BNC 公对公测试线，一端插入前面板 **AO** 端口，另一端连接至 **AI0** 端口。
2. 打开“编辑通道与传感器”，设置 AI0 为：量程 $\pm 10\text{ V}$、`DC` 耦合、**关闭 IEPE**、单位 `V`。
3. 点击“开始预览”启动 AI。
4. 在“信号输出”面板设置：更新率 `48 kS/s`、正弦波、频率 `10 Hz`、幅值 `1.0 V`、偏置 `0.0 V`，点击“开始输出”。
5. 示波器中 AI0 曲线将呈现清晰平滑的 $10\text{ Hz}$、峰峰值 $2.0\text{ V}$ 的正弦波形，测量回读误差优于 $\pm 2\text{ mV}$。

## 7. 数据记录与实验管理

### 7.1 目录组织与自动编号

系统严格保障测试数据的隔离与安全，遵循“**一实验一独立文件夹**”规则：
```text
<记录根目录>/
└── <实验名称>/
    └── <工况名称>-<序号>/
        ├── raw.f64           # 双精度浮点原始电压二进制文件
        └── metadata.json      # 完整会话配置与分段元数据
```
* **实验名与工况名**：在实时采集界面右侧输入。若工况名为空，系统默认采用“未命名”。
* **自动递增**：每次成功完成一次记录，工况序号自动自增（如 `工况-01` $\to$ `工况-02`），杜绝覆盖已有测试文件。

### 7.2 记录模式

1. **手动记录**：选择记录时长为“手动”，点击“开始记录”，状态指示灯变红；实验完成后点击“结束记录”，数据自动落盘封顶并继续保持实时预览。
2. **定时/定长记录**：选择“指定时长”，填入目标秒数（例如 `30.0 秒`）。系统根据实际回读采样率精确换算目标完整扫描帧数，到达设定采样点后自动停止记录、落盘封顶并无缝切回连续预览状态。

### 7.3 暂停与继续写盘

在长时间采集监测过程中，用户可点击“暂停记录”：
* **暂停期间**：硬件数据采集与示波器刷新持续进行，仅停止向磁盘写入 `raw.f64`。
* **继续记录**：点击“继续记录”，系统开辟新的记录分段（Segment）。底层 `metadata.json` 的 `recording_segments` 数组完整保存各分段在源硬件时基上的扫描帧编号，准确记录物理时间流逝，确保回看时忠实展现时间缺口。

### 7.4 双进程防护与后台无损录制

得益于 Rust 独立核心架构，数据流盘由独立的 `labdaq-core.exe` 进程接管：
* 若在流盘记录过程中误关闭或强退 Python GUI 窗口，**后台数据采集与写盘不受任何影响**。
* 定时记录将继续在后台按预设帧数完成并自动收尾；重新打开桌面 GUI 即可自动重连挂接回当前正在进行的会话。

## 8. 数据回看与测量游标

点击导航栏进入“数据回看”页面，可对历史采集记录或外部数据进行精细化复核。

### 8.1 载入记录文件

* **载入原生记录**：点击“打开记录文件夹”，选择包含 `metadata.json` 与 `raw.f64` 的实验目录。系统瞬间完成元数据解析与二进制文件句柄映射。
* **载入 QuickDAQ 历史文件**：点击“打开 HPF 文件”，选择原厂历史 `.hpf` 文件。系统以只读安全模式解析 Double 类型波形数据，保持原厂时基不变。

### 8.2 时间范围导航条 (Time Range Bar)

波形主图下方设有一体化全景时间范围导航条，以蓝色视窗高亮当前屏幕展示的时间区段：
* **平移浏览**：鼠标拖动蓝色视窗主体，可在几十秒乃至数小时的宏观记录中高速左右滑动。
* **范围缩放**：拖拽蓝色视窗两端的边框把柄，可无级拉伸或压缩时间窗口跨度。
* **分块读取**：为保障系统响应速度，单次视窗最大读取 200,000 完整扫描帧，配合底层缓存实现秒级响应。

### 8.3 双测量标线游标 (Cursors A & B)

回看页面默认激活高精度双测量标线系统：
* **游标形态**：
  * **Cursor A**（标线与标签呈青色 Cyan）
  * **Cursor B**（标线与标签呈橙色 Orange）
  * 标线与上下把柄具有 18 像素加宽碰撞响应区，支持鼠标高精度抓取与水平拖动。
* **微秒级数值微调**：在右侧“游标测量”面板中，支持直接在输入框中填入微秒级相对时间，系统自动将游标吸附至最近的真实物理采样点。
* **测量指标面板**：
  * **$t_A$ / $t_B$**：游标 A、B 所在采样点的精确相对时间。
  * **$y_A$ / $y_B$**：游标 A、B 所在位置各通道的瞬时工程数值。
  * **时间差 $\Delta t$**：$t_B - t_A$（物理采样时间差）。
  * **幅值差 $\Delta y$**：$y_B - y_A$（带方向的物理量增量）。
  * **区间峰峰值**（Pk-Pk）：$[t_A, t_B]$ 闭区间内所有有效物理样本的最大值与最小值之差。
  * **间隔倒数 $1/|\Delta t|$**：计算两游标时间差的倒数（单位 $\text{Hz}$），辅助估算周期波形的振动频率。
* **游标归位**：点击“游标回到窗口”按钮，可将位于当前视窗外的标线一键居中召回。

## 9. 数据导出与后处理

在“数据回看”页面完成分析后，点击“导出数据”按钮启动批量导出对话框。

### 9.1 导出配置选项

1. **导出文件格式**：
   * **CSV（逗号分隔值，`.csv`）**：标准 UTF-8 BOM 编码，通用性最强，原生兼容 Excel 与各类脚本。
   * **TXT（制表符分隔值，`.txt`）**：以 Tab 定界，适合部分专业工程软件读取。
2. **导出数值内容**：
   * **仅原始电压（`raw`）**：表头生成 `<通道名>[AI<编号>]_raw_V`（如 `通道1[AI0]_raw_V`），导出未修正的物理电压值。
   * **仅工程单位（`engineering`）**：表头生成 `<通道名>[AI<编号>]_<单位>`（如 `通道1[AI0]_N`），导出扣减零点并经灵敏度换算后的物理值。
   * **双重输出（`both`，默认推荐）**：同一表格中先排列所有活动通道的原始电压列，再排列所有活动通道的工程量列，便于交叉比对与溯源。
3. **时间列格式**：
   * `time_s`（秒，浮点数，保留微秒小数）
   * `time_ms`（毫秒）
   * `time_us`（微秒）
   * `sample_index`（纯硬件采样帧序号）
4. **通道过滤**：仅导出在回看界面左侧“显示与导出通道”列表中勾选的活动通道。

### 9.2 后台分块与取消机制

* 导出引擎在独立工作线程中分块处理（每块 50,000 帧），界面实时显示进度条与百分比。
* 用户可随时点击“取消导出”或关闭对话框，系统将在当前块写入完毕后安全收尾并清理未完成文件，避免内存暴涨或程序界面冻结。

### 9.3 Python / Pandas 快速读取示例

导出文件首行以 `# labdaq_metadata:` 包含完整元数据 JSON 字符串。在 Python 环境中使用 pandas 读取时，只需传入 `comment='#'` 即可无缝解析：

```python
import pandas as pd

# 读取导出的 CSV 文件
df = pd.read_csv("export_data.csv", comment="#", encoding="utf-8-sig")

# 打印数据表结构与前 5 行
print("数据列名:", df.columns.tolist())
print(df.head())

# 提取时间与测力通道进行绘图或自定义分析（以 AI0 默认名称“通道1”、单位“N”为例）
time_s = df["time_s"]
force_n = df["通道1[AI0]_N"]
```

## 10. 系统生命周期与安全退出

### 10.1 规范退出步骤

为保障下一次启动的顺畅并保护外部被测设备，请按以下次序关闭软件：
1. 若正在录盘，点击“结束记录”保存数据。
2. 若正在连续预览，点击“停止采集”。
3. 切换至“信号输出 · AO”面板，点击“停止并归零”，确保 DAC 输出处于安全 $0.0\text{ V}$ 状态。
4. 点击右上角关闭桌面 GUI 窗口。
5. 此时由于无活动采集与无活动输出，后台 `labdaq-core.exe` 进程将自动释放 Open Layers 驱动句柄并静默退出。
