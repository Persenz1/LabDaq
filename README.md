# LabDAQ

面向 **Data Translation DT9837C-BNC** 的中文桌面数据采集软件，以可靠记录、清楚读数和方便取数为目标。项目正在开发，可构建包含 Python 运行时的 Windows 便携测试版。

## 当前架构与便携版（2026-10-26）

采用 **原厂驱动 + Rust 采集核心 + Python / Qt 前端与数据处理**。已撤回 Rust 桌面和数据分析移植，保留原 Qt 的交互、通道表格、分析、回看与比较。Rust 核心的触发、记录、AO 与重连改进继续保留。

真实输入使用 Rust 核心的原厂 Open Layers C 后端，Qt 发送 `vendor`；旧 WinUSB 后端仅保留为显式开发路径。原厂 OEM 运行库和签名驱动已在本机安装并实测，普通使用不需要配置 WinUSB/Zadig。便携包包含 Python、Qt、NumPy/SciPy 与 Rust 核心，原厂驱动及运行库仍需单独安装。

源码运行使用 `launch.ps1`；便携包运行 `dist/LabDAQ/LabDAQ.exe`，保留同目录的 `_internal`。构建命令见[开发环境](docs/开发文档/开发环境.md)。Python 负责回看、频谱、滤波、统计、比较和导出；Rust 核心保留的高级协议能力不代表 Qt 已提供相应入口。

## 开发方向

采用 **Rust 独立采集核心 + PySide6 / Qt 桌面界面**。采集核心负责输入、采集状态和原始写盘，界面负责配置、控制和显示。软件保留原始电压与采集配置，调零、单位换算和显示滤波不覆盖原始记录。

当前面向一台 DT9837C 的四路模拟输入，逐步覆盖该设备适用的 QuickDAQ 功能。默认运行依赖原厂签名驱动和 Open Layers 运行库，不需要 QuickDAQ；不再以摆脱原厂运行时为交付目标。

目前已贯通采集、记录、回看、统计与导出的日常流程，并加入基础 AO 输出。一般功能使用软件模拟信号开发；AO 已通过物理回接 AI0 做短时功能验证。用户已用信号发生器和示波器评估当前测量精度，结论是当前实验需求下无需调整校准或增加软件补偿。

## 当前状态

- AO 支持直流、正弦、方波和三角波，更新率为 10、20、48、96 kS/s 四档，默认 48 kS/s，与 AI 独立。输出页左侧显示设定波形，右侧设置参数；运行时按钮显示红色“正在输出”。界面显示频率上限并限制输入；幅值与偏置组合超出 ±3 V 时禁止启动，核心再次校验并检查原厂回读时钟。AI 与 AO 独立启停，关闭 GUI 后核心继续输出；配置加载不会自动输出。
- 已接通 Rust 原厂输入、电信号模拟、原始记录和界面重连。DT9837C 默认通过原厂 Open Layers SDK 采集；旧 WinUSB/libusb 后端可由核心显式选择。关闭或强制结束 GUI 后，核心继续记录，重开可接回同一组。
- 实机已完成 AI3 的 STM32 直流/正弦输入、采样率边界短采集，以及 GUI 强制退出后的续录。四通道最高采样率短采集通过，但只有 AI3 接入了已知信号；这些检查不属于精度校准或小时级稳定性验证。
- 开发测试保留 Python 协议模拟和有限类型的 HPF 文件输入，正式采集页不显示这些来源入口；HPF 只读回看、CSV/TXT 导出和基础信号分析保持可用。旧 Python 模拟和 HPF 输入尚不支持 GUI 退出后续录。
- 记录按“通用目录/实验名/工况-序号”创建原生记录组，工况序号默认从 1 开始并在每组正常收尾后递增，也可手动修改。时长 0 为手动，正秒数按实际采样率四舍五入到整数帧，到点结束记录并返回预览；Rust 核心在 GUI 断开后仍会自动结束。采集页的实验名、当前工况和序号随记录及 JSON 配置保存，并在核心重连后恢复。记录库可编辑已收尾组的描述信息，不改目录、组号、原始波形或结束状态。
- 通道配置支持测点号、方向、工程单位偏移，以及对启用通道批量设置单位、量程、耦合和 IEPE。工程偏移在扣零点、灵敏度换算和极性处理后应用，不改原始电压，也不是仪器校准。
- 日常记录、回看、统计与导出流程已贯通，已有记录库搜索、精确定位、通道与区间选择、多通道统计、区间导出 CSV/TXT、PNG 存图及单步撤销调零。此前已补齐暂停/继续记录、实时与回看双游标、相对/绝对时间及样本号横轴、每通道独立的近一秒读数模式与小数位设置、记录库多组批量导出。暂停期间预览继续，恢复后保留时间缺口，定长仅累计实际记录帧数。
- 多组只读比较支持不同采样率和非连续物理通道、相对时间/绝对电脑时间/样本号、手动样本零点、显隐与颜色、按单位分图及跨图联动游标。比较不重采样、不填补暂停；可保存/恢复比较布局，导出当前窗口的长表 CSV/TXT 和 PNG。每组最多读取 200,000 帧，总通道值不超过 2,000,000，避免长记录整体载入内存。上述新功能使用模拟记录验证，未做本轮实机测试，尚不代表与全部 QuickDAQ Base 功能等价；操作见[用户使用指南](docs/用户手册/user-guide.md)。
- 2026-10-26 已实测原厂驱动冷态 `DT9837aLD_x64`、运行态 `DT9837aK_x64`，断电重插不回落到 WinUSB。原厂 AI 预览、停止/重启、断电后复采，以及 Qt 和 egui 的真实记录均通过；记录保存 `source = vendor`。原厂路径的最高采样率和小时级运行尚未验证。
- 原厂 AO→AI0 回环完成 0.1 V、10 Hz、48 kS/s 短测，稳定段约 -0.1016～+0.1009 V，停止后归零。停止边界记录到一次约 -0.204 V 瞬态，尚未进一步判定原因；短测不代表 AO 精度或长期稳定性验证。
